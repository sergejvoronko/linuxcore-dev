At the end of April 2026, Canonical's plans to bring AI features to Ubuntu had people asking for an "AI kill switch". Phoronix [reported the clarification](https://www.phoronix.com/news/Ubuntu-AI-Kill-Switch-Opt-In) from Canonical's VP of Engineering, Jon Seager:

- AI features arrive as a **preview, strictly opt-in**, starting with **Ubuntu 26.10**.
- From **27.04**, the initial setup wizard is planned to **ask** which AI features you want.
- There is **no global kill switch**: the features come as **snaps**, and removing them is how you turn them off.
- The default is meant to **always** be **local inference against local models**.

For a homelab **server** that means: nothing AI-related is installed on Ubuntu Server 24.04 or 26.04 today. The question is how to keep an eye on what a server talks to and installs, which applies with or without AI.

## Audit what's there

```bash
snap list                         # every installed snap
pro status                        # Ubuntu Pro attachment and services
systemctl list-timers --all | grep -Ei 'ua-|pro|motd|snap'
apt list --installed 2>/dev/null | grep -Ei 'landscape|popularity-contest'
```

What you might find on a server:

- **snapd** and its snaps: on Ubuntu Server, LXD, for example, comes as a snap.
- **ubuntu-pro-client** (`pro`): manages Ubuntu Pro (ESM, Livepatch). It ships by default and runs periodic checks. Unattached, it doesn't give you anything extra.
- **landscape-client**: only if you or your image installed it. It reports to a Landscape server.
- **motd-news**: fetches news for the login message from Canonical.

## Turn off what you don't want

**News in the login message and in apt output:**

```bash
sudo sed -i 's/^ENABLED=1/ENABLED=0/' /etc/default/motd-news
sudo pro config set apt_news=false
```

**Landscape**, if it's installed and you don't use it:

```bash
sudo systemctl disable --now landscape-client
sudo apt purge landscape-client
```

**Ubuntu Pro client:** leave it installed unless you know what depends on it. Removing it can pull Ubuntu metapackages out with it; check with `apt purge --simulate ubuntu-pro-client` first. If you don't attach a Pro subscription, it doesn't enable any services.

**Snaps:** remove the ones you didn't install deliberately with `sudo snap remove --purge <name>`. When Canonical's opt-in AI snaps appear from 26.10, that's also how you remove them; check `snap list` after release upgrades.

**Removing snapd completely** is possible, but anything you run as a snap (LXD on Ubuntu Server, for example) goes with it:

```bash
sudo snap list                     # check what you'd lose
sudo apt purge snapd
cat <<EOF | sudo tee /etc/apt/preferences.d/no-snapd
Package: snapd
Pin: release a=*
Pin-Priority: -1
EOF
```

The pin stops apt from installing snapd again as a dependency.

## Containers

Ubuntu container images (`ubuntu:24.04`) don't run snapd, the Pro client's services or Landscape, so none of this applies inside them.

## The bottom line

As announced, Ubuntu's AI features are opt-in, local by default, delivered as removable snaps, and not part of current server releases. Keep auditing `snap list` after release upgrades. If you'd rather not depend on how Canonical's plans evolve, Debian is the snap-free alternative.
